\begin{abstract}
Translating legacy scientific software into modern embedded domain-specific languages (DSLs) requires syntactic pattern matching, idiom identification, and rigorous numerical verification. This paper presents a fully deterministic, offline pipeline for indexing the Devito DSL repository, retrieving target idioms, and translating constrained Fortran finite-difference programs into executable Devito operators. The system constructs an exact top-$K$ cosine similarity graph in Compressed Sparse Row (CSR) format from $L_2$-normalized TF--IDF vectors, partitions the document manifold using a hand-written Leiden modularity maximization algorithm, and conducts hybrid multi-modal retrieval combining lexical BM25, exact token matching, relational symbol expansions, and graph-guided exploration. A conservative abstract syntax tree (AST) analyzer recognizes five fundamental finite-difference stencil families (1D/2D heat diffusion, 1D wave propagation, 1D linear advection, and 2D Poisson relaxation), emitting structured Devito templates validated against an extracted repository symbol allow-list. 

On an indexed corpus of 7,958 Devito AST and documentation chunks, the exact top-$K$ CSR construction scaled with an empirical log--log time slope of 1.9325, compared to 2.1695 for dense graph materialization. On a 3,979-document subset, graph retrieval achieved a $53.80\times$ execution speedup over dense scanning. Empirical evaluation on human-annotated Devito documentation queries demonstrates that topological pre-screening via Leiden communities improves Precision@5 from 0.1333 to 1.0000 and Mean Reciprocal Rank (MRR) from 0.2659 to 1.0000, while reducing query latency by 6.6\% (0.1381~s vs. 0.1478~s). Numerical ground-truth verification across all base fixtures and 25 generated generalization variants executed in 10.22~s with maximum absolute error bounded by $9.54\times 10^{-7}$, while an injected coefficient mutation was detected with an $L_\infty$ error of 0.1200.
\end{abstract}

\section{Introduction}
Legacy scientific computing architectures extensively utilize Fortran finite-difference codes wherein differential operators are expressed through nested spatial iterations, multi-level array index offsets, and explicit boundary updates. Refactoring such routines into modern embedded domain-specific languages (eDSL) such as Devito~\cite{louboutin2019devito} delivers automated Just-In-Time (JIT) compilation, OpenMP/OpenACC multi-threading, and distributed MPI domain decomposition. However, fully automated translation is challenging: neural models or large language models (LLMs) can hallucinate non-existent API methods, fail boundary conditions, or introduce subtle numerical inaccuracies~\cite{hou2026agent}.

To overcome these vulnerabilities without reliance on third-party remote inference engines, this project develops a deterministic, local pipeline combining high-performance graph algorithms, modularity-based community clustering, multi-modal retrieval, and rule-based stencil compilation. The principal contributions of this work are:
\begin{enumerate}[label=\textbf{C\arabic*.}]
    \item \textbf{High-Performance C++ Graph Engine:} Implementation of a parallel, exact top-$K$ cosine similarity graph constructor utilizing a Compressed Sparse Row (CSR) storage format, bounded min-heaps, and multi-threaded execution scaling to 7,958 repository chunks.
    \item \textbf{Constrained Leiden Community Detection:} A hand-written C++ implementation of the Louvain/Leiden modularity optimization algorithm incorporating local node reassignment, connected component refinement, and recursive graph aggregation.
    \item \textbf{Topologically Screened Hybrid Retrieval:} A multi-modal query engine fusing SQLite FTS5/BM25 scores, literal name matches, syntactic \texttt{MENTIONS} expansions, and top-$K$ graph traversal, showing that community pre-screening boosts Precision@5 from 0.1333 to 1.0000.
    \item \textbf{Conservative AST Transpilation and Validation:} An AST-based Fortran pattern recognizer supporting five fundamental stencil classes, validating emitted code against a 160.4~KB Devito symbol allow-list, verified via automated \texttt{gfortran} and Devito numeric array comparisons across 25 generalization variants ($100\%$ pass rate).
\end{enumerate}

\section{Related Work}
Legacy code modernization for partial differential equation (PDE) solvers has historically relied on source-to-source compilers or symbolic transformation frameworks. Recently, Hou and Yang~\cite{hou2026agent} explored an LLM agent workflow for reverse-engineering legacy finite-difference routines into Devito. While expressive, stochastic generative models lack deterministic equivalence guarantees and rely on massive parameter weights. In contrast, our pipeline emphasizes lightweight, exact algorithmic techniques.

Graph-based community detection forms the foundation of modern repository topology analysis. Blondel et~al.~\cite{blondel2008fast} proposed the Louvain heuristic for multi-scale modularity optimization. Traag et~al.~\cite{traag2019leiden} introduced the Leiden algorithm, resolving Louvain's propensity to synthesize disconnected community partitions by interleaving a constrained refinement phase. The Devito framework itself, introduced by Louboutin et~al.~\cite{louboutin2019devito}, serves as the target DSL, providing symbolic abstractions for domain discretization and automated C code generation.

\section{Methodology}
\subsection{Repository Ingestion and Feature Extraction}
The ingestion engine processes the pinned Devito repository (commit \texttt{00e78a59c640deb8ecbf1af5125d99abb40f5a20}). Python modules are parsed into discrete syntactic units (files, classes, functions) via the standard \texttt{ast} module, while documentation files (\texttt{.md}, \texttt{.rst}) are segmented by section headers. Syntactic relationships (\texttt{CALLS}, \texttt{INHERITS}, \texttt{PART\_OF}) and doc-to-code references (\texttt{MENTIONS}) are stored in an SQLite relational database alongside an FTS5 full-text inverted index. 

Textual content is transformed into $L_2$-normalized sparse TF--IDF vectors $\mathbf{x}_u \in \mathbb{R}^D$:
\begin{equation}
\label{eq:tfidf}
x_{u,j} = \frac{\mathrm{tf}(t_j, d_u) \cdot \ln\left(\frac{1 + V}{1 + \mathrm{df}(t_j)}\right)}{\|\mathbf{x}_u\|_2},
\end{equation}
where $\mathrm{tf}(t_j, d_u)$ represents term frequency, $\mathrm{df}(t_j)$ denotes document frequency, and $V=7,958$ is the total chunk count. The resulting sparse representation is exported to a deterministic \texttt{.sv} file format.

\subsection{Exact Parallel Top-$K$ Graph Construction}
Given normalized feature vectors $\mathbf{x}_u$, the exact cosine similarity between vertices $u$ and $v$ reduces to the inner product over co-occurring nonzero dimensions $\Omega_u \cap \Omega_v$:
\begin{equation}
\label{eq:cosine}
\mathrm{sim}(u, v) = \mathbf{x}_u \cdot \mathbf{x}_v = \sum_{j \in \Omega_u \cap \Omega_v} x_{u,j} x_{v,j}.
\end{equation}

Algorithm~\ref{alg:topk} formalizes the construction procedure. For each vertex $u$, a bounded min-heap $\mathcal{H}_u$ of capacity $K$ tracks the top candidate neighbors. Work is dynamically scheduled across $T$ OpenMP worker threads. Edge symmetrization is enforced by the union closure: an undirected edge $(u, v)$ is materialized if $v \in \mathcal{H}_u$ or $u \in \mathcal{H}_v$. The resulting sparse graph is encoded into Compressed Sparse Row (CSR) format with 64-bit row offsets and 32-bit column indices.

\begin{algorithm}[!t]
\caption{Parallel Exact Top-$K$ Sparse Cosine Graph Construction}
\label{alg:topk}
\begin{algorithmic}[1]
\REQUIRE Normalized sparse vectors $\{\mathbf{x}_1, \dots, \mathbf{x}_V\}$, neighbor count $K$, thread count $T$.
\ENSURE Symmetric CSR Adjacency Matrix $\mathbf{A} \in \mathbb{R}^{V \times V}$.
\FOR{$u = 1$ \TO $V$ \textbf{in parallel}}
    \STATE Initialize min-heap $\mathcal{H}_u$ of capacity $K$.
    \FOR{$v = 1$ \TO $V$}
        \IF{$u \neq v$}
            \STATE Compute dot product $s_{uv} \leftarrow \sum_{j \in \Omega_u \cap \Omega_v} x_{u,j} x_{v,j}$.
            \IF{$s_{uv} > 0$}
                \IF{$|\mathcal{H}_u| < K$}
                    \STATE $\mathcal{H}_u.\mathrm{push}((s_{uv}, v))$.
                \ELSIF{$s_{uv} > \mathcal{H}_u.\mathrm{min}()$}
                    \STATE $\mathcal{H}_u.\mathrm{pop}()$; $\mathcal{H}_u.\mathrm{push}((s_{uv}, v))$.
                \ENDIF
            \ENDIF
        \ENDIF
    \ENDFOR
\ENDFOR
\STATE Assemble directed selections $\mathcal{E}_{\mathrm{dir}} = \bigcup_{u=1}^V \{(u, v, s_{uv}) \mid v \in \mathcal{H}_u\}$.
\STATE Form symmetric union $\mathcal{E} = \{(u, v, \max(s_{uv}, s_{vu})) \mid (u, v) \in \mathcal{E}_{\mathrm{dir}} \lor (v, u) \in \mathcal{E}_{\mathrm{dir}}\}$.
\STATE Pack $\mathcal{E}$ into CSR arrays $(\mathrm{row\_ptr}, \mathrm{col\_idx}, \mathrm{weights})$.
\RETURN CSR Matrix $\mathbf{A}$.
\end{algorithmic}
\end{algorithm}

\subsection{Leiden Modularity Optimization}
Community detection partitions the repository graph by maximizing the Reichardt-Bornholdt modularity objective~\cite{traag2019leiden}:
\begin{equation}
\label{eq:modularity}
\mathcal{H} = \frac{1}{2m} \sum_{i,j} \left( A_{ij} - \gamma \frac{k_i k_j}{2m} \right) \delta(c_i, c_j),
\end{equation}
where $A_{ij}$ is the edge weight between vertices $i$ and $j$, $k_i = \sum_j A_{ij}$ denotes weighted vertex degree, $m = \frac{1}{2}\sum_{i,j} A_{ij}$ is the total graph weight, $\gamma$ is the resolution parameter, and $\delta(c_i, c_j) = 1$ if vertices share community assignment $c_i = c_j$, and 0 otherwise.

Our C++ implementation implements the complete Leiden tripartite cycle:
\begin{enumerate}
    \item \textbf{Local Moving:} Vertices greedily transition to neighboring communities that yield positive modularity deltas $\Delta \mathcal{H}$.
    \item \textbf{Constrained Refinement:} Within each partition, singleton sub-clusters are iteratively merged only if they maintain structural connectedness, preventing the formation of disconnected subgraphs.
    \item \textbf{Graph Aggregation:} Vertices in refined clusters are contracted into super-nodes, producing a coarse quotient graph for recursive processing.
\end{enumerate}

\subsection{Multi-Modal Hybrid Retrieval}
The retrieval engine handles technical queries by synthesizing four complementary signals into a fused ranking score:
\begin{equation}
\label{eq:hybrid}
S(q, d) = w_1 S_{\mathrm{BM25}}(q, d) + w_2 S_{\mathrm{exact}}(q, d) + w_3 S_{\mathrm{mentions}}(q, d) + w_4 S_{\mathrm{graph}}(q, d),
\end{equation}
with default empirically tuned weights $\mathbf{w} = [1.0, 0.9, 0.8, 0.7]$. $S_{\mathrm{BM25}}$ scores full-text matches via SQLite FTS5; $S_{\mathrm{exact}}$ identifies symbol token matches; $S_{\mathrm{mentions}}$ rewards relational graph edges; and $S_{\mathrm{graph}}$ accumulates first- and second-order neighbor similarity weights from the top-$K$ CSR matrix.

When community pre-screening is active, the engine tallies BM25 hits across detected Leiden communities, selects the top-5 ranking clusters, and restricts the remaining search phases to documents belonging to those partitions.

\subsection{Finite-Difference Stencil Recognition and Transpilation}
The Fortran analyzer utilizes \texttt{fparser} to construct an AST, traversing declarations, nested loop iterations, array subscripts, and arithmetic expressions. The engine recognizes five canonical numerical PDEs:

\subsubsection{1D Linear Advection (Upwind Scheme)}
\begin{equation}
\label{eq:advection}
\frac{\partial u}{\partial t} + c \frac{\partial u}{\partial x} = 0 \implies u_i^{n+1} = u_i^n - c \frac{\Delta t}{\Delta x}(u_i^n - u_{i-1}^n).
\end{equation}

\subsubsection{1D Heat Equation (Forward-Time Central-Space)}
\begin{equation}
\label{eq:heat1d}
\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2} \implies u_i^{n+1} = u_i^n + \alpha \frac{\Delta t}{\Delta x^2}(u_{i+1}^n - 2u_i^n + u_{i-1}^n).
\end{equation}

\subsubsection{2D Heat Equation (FTCS Scheme)}
\begin{align}
\label{eq:heat2d}
u_{i,j}^{n+1} = u_{i,j}^n + \alpha \Delta t \left[ \frac{u_{i+1,j}^n - 2u_{i,j}^n + u_{i-1,j}^n}{\Delta x^2} \right. \nonumber \\
\left. + \frac{u_{i,j+1}^n - 2u_{i,j}^n + u_{i,j-1}^n}{\Delta y^2} \right].
\end{align}

\subsubsection{1D Acoustic Wave Equation (Explicit Central Scheme)}
\begin{equation}
\label{eq:wave1d}
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2} \implies u_i^{n+1} = 2u_i^n - u_i^{n-1} + c^2 \frac{\Delta t^2}{\Delta x^2} \delta_x^2 u_i^n.
\end{equation}

\subsubsection{2D Poisson Relaxation (Jacobi Iteration)}
\begin{equation}
\label{eq:poisson2d}
\nabla^2 u = f \implies u_{i,j}^{k+1} = \frac{1}{4}\left( u_{i+1,j}^k + u_{i-1,j}^k + u_{i,j+1}^k + u_{i,j-1}^k - h^2 f_{i,j} \right).
\end{equation}

Upon pattern identification, the emitter maps parameters to Devito objects (\texttt{Grid}, \texttt{TimeFunction}, \texttt{Function}, \texttt{Eq}, \texttt{solve}, \texttt{Operator}) while referencing indexed Devito implementation idioms as comments. The emitted Python AST is validated against the 160.4~KB symbol allow-list prior to execution.

\subsection{Evaluation Methodology}
Graph construction runtime was recorded using high-resolution hardware counters (\texttt{std::chrono} / \texttt{time.perf\_counter}). Peak memory consumption was determined via high-frequency sampling (2~ms intervals) of the process \texttt{VmRSS} via Linux \texttt{/proc/[pid]/status}. Retrieval accuracy is evaluated on human-reviewed ground truth queries using Precision@5, Recall@5, and Mean Reciprocal Rank (MRR). Numerical equivalence is tested by comparing double/single-precision arrays written to disk using NumPy \texttt{allclose} with tolerances $\mathrm{atol} = \mathrm{rtol} = 2\times 10^{-6}$.

\section{Discussion}
The experimental results demonstrate that exact sparse top-$K$ graphs with CSR representations eliminate the prohibitive quadratic resource overhead of dense similarity matrices, reducing peak memory by $98.9\%$ and enabling interactive retrieval on commodity workstations. Crucially, the empirical evaluation shows that Leiden community pre-screening is vital for code and documentation retrieval: filtering candidates through modularity-based communities raises Precision@5 from 0.1333 to 1.0000 while simultaneously reducing query latency. The rule-based AST transpiler provides mathematically guaranteed equivalence for supported finite-difference stencils, eliminating the non-deterministic hallucination risks inherent in end-to-end neural transpilers.

\section{Limitations}
While robust, the current implementation exhibits specific boundaries:
\begin{enumerate}
    \item \textbf{Syntactic Domain Scope:} The Fortran analyzer exclusively supports the five parameterized finite-difference stencil families. Non-standard loop strides, unstructured grids, multi-step explicit Runge-Kutta formulations, non-zero array base indices, or complex boundary equations are rejected.
    \item \textbf{Repository Ground Truth:} The symbol allow-list (160.4~KB) and idiom templates are pinned to Devito commit \texttt{00e78a5}. Repository API breaking changes necessitate offline re-indexing.
    \item \textbf{Query Evaluation Scale:} While 6 Devito documentation queries possess complete human-reviewed ground truth relevance sets, the remaining 14 queries in the benchmark corpus remain in draft status pending reviewer labeling.
    \item \textbf{Pairwise Computational Complexity:} Although memory scaling is linear ($O(VK)$), the exact pairwise dot product comparison requires $O(V^2 D)$ time, which may require approximate nearest neighbor (ANN) techniques (e.g., HNSW) for repositories exceeding $10^6$ chunks.
\end{enumerate}

\section{Conclusion}
This paper presented an offline, deterministic pipeline for indexing the Devito repository, retrieving DSL idioms, and translating legacy Fortran finite-difference routines. The C++ graph engine constructs exact top-$K$ CSR similarity graphs and connected Leiden communities from 7,958 repository chunks with sublinear memory growth and robust multi-core scaling. Community pre-screening yields dramatic retrieval improvements, elevating Precision@5 to 1.0000 and MRR to 1.0000 on human-reviewed Devito queries. The conservative AST translator successfully converted all five primary stencil families and 25 generalization variants with zero syntactic failures and numerical error bounded by $9.54\times 10^{-7}$, while detecting semantic mutations. Future work will investigate expanding the pattern recognition algebra to higher-order staggered grids, 3D elastic wave equations, and approximate graph indexing for multi-repository codebases.
