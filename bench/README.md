# Benchmarks

`run_benchmarks.py` creates deterministic synthetic sparse vectors and a synthetic four-topic document corpus, then invokes the actual C++ graph program and Python retrieval modules. It writes measured CSV/PNG outputs, machine information, and fitted log-log slopes into the requested output directory (default `bench/results`). The generated documents are not Devito documentation. Pass `--devito-database` and `--allowed-names` to compile, emit, and compare each supported Fortran fixture; `conversion_validation_status.csv` and `conversion_benchmark.csv` then contain the measured per-sample status, pass rate, and runtime. Without those options, conversion status says it was not measured.

Example:

```sh
PYTHONPATH=python:/path/to/devito .venv/bin/python bench/run_benchmarks.py --graph-tool /tmp/metaphrasis-build/graph_tool --output bench/results --seed 1 --devito-database data/devito.sqlite --allowed-names data/devito.allowed_names
```

The dense-vs-top-K RSS measurement samples `/proc/<pid>/status` every 2 ms and reports the largest observed RSS. Times are wall-clock times from `perf_counter`. Run on an otherwise idle machine for repeatable measurements. No interpretation is generated by the script.

## Indexed Devito graph benchmark

`real_devito_benchmarks.py` consumes `data/devito.sv` and `data/devito.sqlite`, emits CSV/PNG results labeled with the indexed corpus, measures top-K through the complete index, and defaults dense comparisons to half the row count. It records any larger dense sizes as skipped. Use `--dense-limit N` to set the maximum dense size; requesting the full row count is exact but may be prohibitively slow or memory intensive. Dense-versus-top-K retrieval uses the largest dense-completed subset and records that `n` alongside the full index size. The no-limit K row has its own `n` because it uses the completed dense subset when full dense is skipped.

Recall columns are empty with an explicit status until reviewed label rows are passed with `--labels`. The 20 supplied query records remain DRAFT and are not ground truth. The full-index dense graph did not complete in the latest run, so no full-index dense retrieval ratio is reported.
